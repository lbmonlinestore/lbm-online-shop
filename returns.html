Our Returns Policy

Please read the following before submitting a request.

Three-day request period
Return and exchange requests must be submitted within 72 hours after your order has been marked as delivered.
  • Your order must be verified using your order number and checkout phone number.
  • You can only request a quantity that you purchased.
  • Every request is reviewed by LBM Online Shop.
  • Submitting a request does not automatically mean it has been approved.
  • Keep your tracking code so you can follow your request.
